# Resume Builder

## Introduction

Resume Builder is a beginner-friendly command-line Python project that helps users create a simple, structured resume by entering their personal, education, experience, project, skills, and achievement details.

The program collects the information through a series of questions and provides different options to preview, save, search, and review the resume. It is designed using basic Python concepts so that it is easy to understand, run, and modify.

## Features

- Create a new resume through an interactive menu
- Enter personal information such as name, email, phone, location, and profile summary
- Add multiple education records
- Add internships, work experience, or volunteering
- Add multiple projects and the tools used
- Add and manage skills
- Add achievements and certificates
- Choose between Classic and Compact resume layouts
- Preview the generated resume
- Save the resume as a `.txt` file
- Check the completeness of important resume sections
- Search for specific words or phrases in the resume
- Sort skills alphabetically
- Reverse the order of entered skills
- Compare existing skills with skills required for a job
- Count the number of words in the profile summary
- Get a random writing prompt for improving resume content
- View a guide explaining the different resume sections
- Validate email addresses, phone numbers, menu choices, and other user inputs
